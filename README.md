# fda-r-submission-guide
The app is a Shiny guider for R developers who already know the SAS FDA path. It keeps the same eCTD Module 5 package — SDTM, ADaM, TLFs, XPT, Define-XML, the ADRG, and programs a reviewer can rerun — and shows the R equivalent of each SAS step. The worked study is synthetic ABC-001, not a real trial.
